raylib 6.0 Embedded Dependency Notices
======================================

Tanks 3D macOS release builds statically link raylib 6.0. The resulting
executable therefore contains code from raylib's embedded dependencies even
though their source files are not vendored in this repository.

The inventory and notices below were taken from the exact raylib 6.0 tag:
https://github.com/raysan5/raylib/tree/6.0/src/external

Tag commit:
dbc56a87da87d973a9c5baa4e7438a9d20121d28

Official source archive SHA-256:
2b3ee1e2120c7a0796b33062c7e9a694dd8a8caa56a96319ac8c8ecf54a90d0b

This inventory covers the default macOS desktop modules present in the
statically linked release: GLFW 3.4; GLAD 2.0.0-beta and Khronos material;
sdefl/sinfl; rprand; stb_image, stb_image_resize2, stb_image_write,
stb_perlin, stb_rect_pack, stb_truetype, and stb_vorbis; QOI; rltexgpu;
miniaudio; dr_wav; dr_mp3; jar_mod; jar_xm; QOA and qoaplay; par_shapes;
tinyobj_loader_c; cgltf and its embedded jsmn parser; vox_loader; and m3d.
Platform-specific or disabled raylib sources are not claimed as part of this
macOS inventory.
In particular, the default raylib 6.0 macOS configuration leaves
SUPPORT_FILEFORMAT_GLTF_WRITE and SUPPORT_FILEFORMAT_FLAC disabled, so
cgltf_write.h and dr_flac.h are intentionally absent from this binary-specific
inventory.
