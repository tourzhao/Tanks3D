## Validation and outstanding acceptance

The code was validated with `make clean`, `make test test-ai`,
`make test-sanitize test-ai-sanitize`, and `make test-dist DIST_CHANNEL=alpha.5`.
The Python training/AI suite contains 59 tests. Native rules/observations match the
selected Python reference on all 35 maps and three complete seeded episodes.
The review additionally executed 70 short headless runs and 73,377 decisions;
see [per-stage results](runtime-probe.log) and the [probe source](runtime_probe.cpp).
The probe can be compiled against the normal non-main objects and raylib, like
`tests/ai_player_tests.cpp`. It uses idle P1 input and is not a
human-cooperation or GPU-performance acceptance run.

The [2026-09-14 release review](ai-release-review.md) records the remaining
physical keyboard/Bluetooth-controller and human/AI acceptance work, missing
CI parity/coverage wiring, and candidate-bound clean-Mac/30-minute gates.
The release gate failed on the then-dirty worktree; committing this source does
not itself complete those remaining gates. A source PR may be reviewed while
release acceptance is pending. The previous Alpha candidate/tag is immutable.

`ai-validation.json` and `ai-review-results.json` are copies of local receipts,
not publication approvals. Their full-log paths refer to the original local QA
directories; those larger directories are not included in this preview export.
