# 坦克建模标准：以实车为基础的卡通化

更新：2026-09-29。用户再次明确的当前要求。本文是后续美术工作的统一入口，
优先于历次试版里“统一大炮塔”“全车后移炮塔”或“放弃卡通、追求写实”的方向。
现有实现与截图记录仍见 [CARTOON_TANKS.md](CARTOON_TANKS.md)，不把制作标准
当作当前模型已经全部达标的证明。

**当前保留已有造型，不再继续扩大卡通化。** 用户最新要求是在各车型现有结构上
加粗炮管、加宽车辆、加厚底盘，取得更短粗厚实的视觉比例；不因此再放大炮塔、
统一圆化各车或消除长短炮差异。具体幅度与实拍见[尺寸记录](TANK_PROPORTIONS.md)。
以下以实车为依据、逐车保留识别点的流程继续适用。

本轮继续细分[十二车的装甲面与炮塔截面](TANK_ARMOR_SURFACES.md)。同为方形炮塔，
也要分别检查前颊展开、侧壁内倾、顶肩宽度与尾舱转角；不能统一倒圆后只改尺寸。
焊接板检查真实顶点共面，铸造肩部才使用局部平滑。附件从实际支撑面取得挂点。

## 核心原则

**先根据具体实车型号的数据和结构建立比例，再对该车型做卡通化。**
卡通化用于增强它本来就有的特点：T-34 的前置炮塔、Sherman 高而厚实的车体、
M60 的较高铸造体量、M1 的低平楔形结构应更容易看见，而不是被通用比例抹平。
这里 Sherman 的“厚”指可见车体的高度与体积感，不指装甲板厚度或防御数值。

允许适度加粗炮管、放大关键炮盾/舱盖、简化曲面与微小附件、设计大色块。
每次调整都要核对该车的布局与轮廓；同一个增粗或缩放系数不能自动成为十二车
全部适用的美术结论。国家涂装、玩家标记和文字不能代替车型本身的区分。

## 每次动模型之前

1. **锁定子型号。** 记录炮型、炮塔型、悬挂和车首版本；沿用下表的选型。
2. **先读资料再下手。** 读取该车已有尺寸、底盘和身份资料。资料缺失、矛盾或
   准备改变关键特征时，再查手册、制造商或博物馆；不需要每轮重复全网搜索。
3. **写下本轮的车型卡。** 在实现记录或 `build/` 下的 QA 记录中列出来源、
   测量定义、至少三个必须保留的结构点、本次拟夸张的部位和幅度。
4. **分开记录三类依据。** 实车尺寸/手册事实；照片或图形比例估计；为游戏可读性
   做的原创调整。缺失尺寸标注未知，不把代码常数或目测值称为实车数据。
5. **先核对结构，再看材质。** 固定相机的侧面、正面/前斜面灰模与基线对比，
   确认炮塔前后、车体厚薄、轮列、炮盾及长短炮关系，之后才调整色块和附件。

有明确车体长、宽等数据时先建立其比例，用等比整车缩放适配等级体量，再逐项
记录卡通化偏移。车体长度、炮向前全长、炮塔主体顶高、指挥塔总高必须分开。
炮塔轴线位置与炮塔包围盒中心也必须分开，后部尾舱会使二者不同。
当前尺寸研究中的归一化建议**不是**十二车完整实测数据；不要机械复制为真值。

## 验收顺序

逐车确认上表特征 → 同相机同尺寸灰模比较 → 真实地图默认视角 →
四方向与边界视角 → Pixel 开关 → P1/P2、敌军与移动开炮。
近景中的细节不能代替正常尺寸下的识别；颜色不同也不能代替轮廓不同。

同级体量接近、升级可辨继续保留，但不是十二车共用同一长宽高比的理由。
历史实车并非按游戏等级严格递增，尤其不能为升级感把所有高低特征反转。
碰撞、弹道、射速、伤害、地图、随机数和正常镜头保持原契约。可见炮口与
特效必须连接正确；不能通过移动历史炮塔布局来掩盖挂点问题。

## 当前基线核对与资料边界

和 [Museum of the American G.I. 的 M4A3](https://americangimuseum.org/collections/restored-vehicles/m4a3-sherman-1942-1943/)

整车尺寸。馆藏页并未提供精确座圈坐标或上车体高度；不得把它们说成 T-34
前移百分比、Sherman 甲板高度的直接测绘依据。布局判断沿用已归档参考，
炮塔位置和车体截面须继续对照实际模型与画面。

当前两端代码已分别保留前置 T-34 与较高 Sherman 车体。Godot 的美术检查
已有实际顶点的 T-34 前置关系，以及 Sherman/M26、M60/M26、M1/M60 高度关系。
raylib 原有 T-34 前置检查，本次补充美系实际生成车体/塔体高度关系回归检查。
