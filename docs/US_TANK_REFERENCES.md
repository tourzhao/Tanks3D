# 美军四级坦克：造型与绿色迷彩参考

整理日期：2026-09-26。用户指定顺序：**M4 → M26 → M60 → M1**。

以下保留实车照片与制作参考。2026-09-26 的[卡通试版](CARTOON_TANKS.md)已接入
M4A3(75) / M26 / M60A3 / M1A1 和陆军绿色迷彩；四级对应内部 level 0–3。
这是游戏风格化造型，不是各子型号的精密复原。

## 选定的造型参考

底盘和炮塔采用三国共用的[四级尺寸标准](TANK_PROPORTIONS.md)：逐级增大，
同级大小接近，再以各车型的截面、肩部和结构区分身份。现已用于[卡通试版](CARTOON_TANKS.md)。

用户指定的是车族名。为避免把不同改型的车体、炮塔和悬挂拼在一起，建议按以下
具体子型号制作；游戏展示可以保留 M4 / M26 / M60 / M1 的简短名称。

| 游戏等级 | 主参考型号 | 优先保留的视觉特征 | 街机化处理建议 |
| --- | --- | --- | --- |
| 1 / level 0 | M4A3 Sherman，75 mm、VVSS 悬挂 | 较高的焊接车体、较小的圆铸炮塔、前部圆润传动罩、三组双轮台车 | 保留高车身与小圆炮塔的反差，炮管短粗，台车分成三个清楚的大节奏 |
| 2 / level 1 | M26 Pershing，普通 90 mm 版本 | 更低的车身、宽厚炮塔与大炮盾、明显的炮口制退器、六个独立大负重轮 | 增加肩部宽度，压低车体，放大炮盾与制退器，避免成为放大的谢尔曼 |
| 3 / level 2 | M60A3 | 前部收窄的长铸造炮塔、高指挥塔、斜车首、炮管热护套 | 保留长炮塔与高指挥塔这一组合；不套用早期 M60 接近 M48 的圆炮塔 |
| 4 / level 3 | M1A1 Abrams | 宽而有棱角的炮塔、低平车体、长侧裙、炮塔尾部储物篮 | 用楔形大块面和长尾舱区别前三辆；简化附件，保留宽重的顶级轮廓 |

表中的街机化处理是原创设计建议，不是史实尺寸。主参考照片均已实际打开查看。
M26 属于二战末期车型，博物馆资料记载其于 1945 年投入使用。[R2]
M60A3、M1A1 是为本项目选定的战后子型号，不把它们称作最初的 M60 或 M1。

## 游戏涂装方向

目标是美国陆军车辆的**绿色为主、深棕与近黑色大斑块**，以 R4 的实车照片作为
色块组织参考，R5 的官方资料作为 woodland 涂装背景。不是把军服上的小迷彩图案
平铺到坦克，也不使用沙漠色。

建议第一轮材质试样使用以下屏幕颜色；它们是项目自定的 sRGB 起点，**不是官方色卡
的精确 RGB 换算，也不是从有色光照照片直接测得的标准值**：

| 用途 | 建议起点 | 处理 |
| --- | --- | --- |
| 绿色主漆 | `#55613D` | 延续当前国家主色，作为最大连续面积 |
| 棕色斑块 | `#594B37` | 少量宽而不规则的色带，避免平均撒点 |
| 近黑斑块 | `#292E29` | 打断轮廓但不吞没炮盾、舱盖和车首朝向 |
| 装甲亮面 | 随基础色调亮、略暖 | 用光照与手绘色阶表现体积，不能作为第四种迷彩色随机铺开 |

绿 / 棕 / 黑约 60 / 25 / 15 可作为第一版图案面积起点；这是为游戏识别度选择的
设计比例，不是军方规定。最后需要在正常游戏镜头和 Pixel Style 开关下重新判断。
贴图应固定在车辆局部坐标，不能移动时游动。履带橡胶、裸露金属、镜片、P1/P2 标记
继续使用独立材质；尤其要检查 P2 绿色身份标记在绿色装甲上是否足够清楚。

把这套统一迷彩用于 M4、M26，是用户要求下的跨年代游戏美术方案，不宣称为二战
原装涂装复原。四辆车通过轮廓区分等级，通过共同迷彩区分国家。

## 接入前的核对清单

- `src/game/vehicle_identity.h`：当前 USA 映射和名称是 M4A3(75) / M26 / M60A3 / M1A1。
- `src/wwii_tank_model.h`、`src/arcade_tank_roster.h`、`src/chaffee_sample_model.h`：raylib 造型与配色路径。
- `godot/sample/art.gd`：Godot 车型名称、各级造型和国家材质路径。
- 美军敌人也需保持对应的车型身份；敌军国家排除规则、玩家身份、升级数值和炮口挂点不变。
- 外形仍采用当前紧凑街机比例。实车照片用于结构识别，不要求原尺寸等比缩小。
- 当前资料足够开始四车轮廓草模；精修之前还需补查 M4/M26 的顶部、后部结构。
  本次没有收集可直接分发的 GLB、贴图或 SNK 游戏素材。
