# Tanks 3D v0.1.0-alpha.4 — Public Playtest

This is the first public playtest of **Tanks 3D**, a non-commercial,
fixed-camera isometric tank game inspired by classic four-direction arcade
combat. It is an early pre-release intended for players who are comfortable
reporting bugs and using macOS's **Open Anyway** flow.

## Download

Download **`Tanks3D-0.1.0-alpha.4-macos-arm64-macos26.0.zip`** from the assets
below. Do not download GitHub's automatically generated “Source code” archives
unless you intend to compile the game yourself.

- Platform: Apple Silicon (`arm64`)
- Minimum system: macOS 26.0
- ZIP SHA-256: `9a4826b6e5809fceed65d0c227ffad35751ee87c160c2758412c05d8dc875e0b`
- Signing: ad-hoc integrity signature; not Developer ID signed or notarized

Verify the download before opening it:

```sh
shasum -a 256 Tanks3D-0.1.0-alpha.4-macos-arm64-macos26.0.zip
```

Extract the ZIP, right-click `Tanks3D.app`, and choose **Open**. If macOS blocks
the first launch, use **System Settings > Privacy & Security > Open Anyway**.
Never disable Gatekeeper globally.

## Highlights

- 35 deterministic stages with one-player and local two-player modes.
- Fixed 45-degree camera and four-direction movement.
- United States, Soviet, and German light-to-super-heavy vehicle progressions.
- Destructible national bases, shell cancellation, HP, respawns, and streaks.
- Nine pickups, including conditional Bandage healing and Star upgrades.
- Classified end-of-stage tank-destruction report.

## Controls

- Menus: Arrow keys or `WASD`; `Enter` or `Space` confirms.
- Player 1: Arrow keys; `Space`, Right Option, or Right Control fires.
- Player 2: `WASD`; `F`, Left Option, or Left Control fires.
- Battle: `Enter` pauses, `Esc` returns to setup, and `R` restarts.
- Display/stage: `F8` quality, `F11` borderless, and `N`/`B` stage.

## Alpha status

The exact candidate passed the automated build, unit/integration, architecture,
sanitizer, bundle, signature, and archive-integrity gates. The project owner has
completed playtest checks, but the repository's stricter independent human-QA,
clean-Mac, performance, and approval evidence archive has not yet been
assembled. This release is therefore published as a **pre-release**, not as a
stable or formally approved build.

Please report crashes, stuck enemies, collision problems, missing audio, visual
artifacts, and controller/keyboard issues through GitHub Issues. Include your
Mac model, macOS version, game mode, stage, and reproduction steps.
