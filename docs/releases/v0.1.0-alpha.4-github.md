# Tanks 3D v0.1.0-alpha.4 — Public Playtest

Classic four-direction tank combat rebuilt on a fixed 45-degree 3D battlefield.
Play solo or local co-op across 35 destructible stages.

![Tanks 3D local two-player firefight](https://raw.githubusercontent.com/tourzhao/Tanks3D/c8deed675d2b675a9de951a6e1e6f97471d95b88/docs/assets/marketing/v0.1.0-alpha.4/gameplay-coop.png)

## Download

**Apple Silicon · macOS 26.0 or later**

Download **`Tanks3D-0.1.0-alpha.4-macos-arm64-macos26.0.zip`** under Assets,
not GitHub's “Source code” archives. Verify it with the attached `.sha256` file.

Extract it, right-click `Tanks3D.app`, and choose **Open**. If blocked, use
**System Settings > Privacy & Security > Open Anyway**.

## Highlights

- Destructible battlefields, national bases, and full-map radar.
- United States, Soviet, and German light-to-super-heavy tank lines.
- Nine pickups, upgrades, HP, streaks, shell cancellation, and battle reports.

![Tanks 3D one-player battle](https://raw.githubusercontent.com/tourzhao/Tanks3D/c8deed675d2b675a9de951a6e1e6f97471d95b88/docs/assets/marketing/v0.1.0-alpha.4/gameplay-solo.png)

## Controls

- **P1:** Arrow keys; `Space`/Right Option/Right Control fires.
- **P2:** `WASD`; `F`/Left Option/Left Control fires.
- `Enter` pauses · `Esc` returns to setup · `R` restarts.
