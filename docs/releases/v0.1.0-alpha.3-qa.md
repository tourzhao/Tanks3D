### Development-Mac diagnostics (supplemental only)

At 2026-08-08 15:06 EDT, the extracted candidate on the development Mac produced
the following results:

- `codesign --verify --deep --strict --verbose=4` passed. Inspection reported
  `Signature=adhoc`, no Team Identifier, and CDHash
  `6185f1fd7de87fb186796facfdd645cb5e0568a9`.
- The extracted app had `com.apple.provenance` but no
  `com.apple.quarantine` attribute, so this was not a downloaded-quarantine
  test.
- `spctl --assess --type execute --verbose=4` exited 1 with
  `internal error in Code Signing subsystem`; it did not produce a passing
  Gatekeeper assessment.
- `syspolicy_check distribution` did not complete within 60 seconds and was
  interrupted. It is inconclusive, not a pass.
- Full exact-candidate capture logs showed Core Audio initialization and all 22
  packaged OGG files loading through raylib. Each of the seven capture
  processes rendered and saved its frame, released audio/graphics resources,
  and exited 0. This proves runtime loading and cleanup on this Mac, not audible
  hardware quality.

These observations narrow the remaining work but do not replace the required
quarantined download on a clean Mac or a human listening test.
