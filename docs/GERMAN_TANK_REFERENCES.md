# 德国四级坦克：造型与深灰涂装参考

整理日期：2026-09-26。用户指定顺序：**豹式 → 虎王 → 豹一 → 豹二**，
统一使用二战早期装甲车辆的“德国灰”方向。这项要求取代德国雪地迷彩的后续美术目标。

以下保留实车照片与制作参考。2026-09-26 的[卡通试版](CARTOON_TANKS.md)已接入
Panther A / Tiger II / Leopard 1 / Leopard 2A4 和哑光深灰涂装。四级对应内部 level 0–3；
以下子型号是制作参考选择，不是用户额外指定的要求。

## 四级造型

| 等级 | 选定主参考 | 关键外形 | 街机化处理 |
| --- | --- | --- | --- |
| 1 / level 0 | Panther Ausf. A，豹式 A 型 | 大斜车首、向上收窄的炮塔、弧形炮盾、交错大轮 | 保留楔形车体与较窄炮塔的反差，炮盾成为主要识别点；收短炮管时仍保留炮口特征 |
| 2 / level 1 | Tiger II，虎王量产炮塔型 | 厚重斜装甲车体、较长且厚实的炮塔、平直炮塔前板、宽履带 | 强调炮塔肩部、车首厚度与履带重量；不能只是放大豹式，也不沿用虎 I 的直立车首 |
| 3 / level 2 | Leopard 1，早期量产基本型 | 圆润铸造炮塔、较低的车体、七轮悬挂、无制退器的炮口、炮根上方探照灯 | 用收圆的炮塔、外露负重轮和一个放大的探照灯形成性格；保留轻巧结构，但游戏中的底盘占地和炮塔主体比二级更大 |
| 4 / level 3 | Leopard 2A4 | 宽大方形炮塔、平直炮塔前脸、车首大斜面、长侧裙 | 宽肩、低重心、清楚的炮根；利用炮塔前侧观察装置的不对称关系，区别其他三级 |

以实车结构建立差异，再按现有紧凑街机语言设计原创网格。按最新要求，底盘和炮塔
主体必须逐级增大，同级三国大小接近；共用[四级尺寸标准](TANK_PROPORTIONS.md)。
历史尺寸不能直接决定游戏缩放，等级数值也不来自这些车辆的真实性能。

豹一参考基本型，不混用 A3/A4 的焊接棱角炮塔或 A5 附加装甲；豹二参考 A4，
不混入 A5 的尖楔附加装甲和 A6 的加长炮管。[R3/R4]
虎王采用量产平前脸炮塔，不混用预生产弧形前脸；馆方说明这两种炮塔均由 Krupp
设计制造，本文使用“量产炮塔”而非含混的“亨舍尔炮塔”。[R2]

## “德国灰”的材质方向

以早期装甲车辆 **Dunkelgrau / Panzer Grey** 的深灰观感为方向，现代色名对照见
[RAL 7021 Schwarzgrau / Black grey](https://www.ral-farben.de/farbe/ral-classic/ral-7021/9240)。
目标是低饱和、哑光的深灰装甲。此前军服灰绿和雪地白的方向不再用于后续德国坦克。

| 用途 | 原创 sRGB 试样起点 | 处理 |
| --- | --- | --- |
| 装甲主色 | `#45494B` | 连续的大色块，不额外铺三色迷彩 |
| 装甲亮面 | `#747671` | 略暖，沿主要受光面组织，避免银色金属感 |
| 装甲暗面 | `#2C343B` | 略冷，保留炮塔与车体的分层 |
| 履带橡胶、深缝 | `#171C1D` | 比装甲更暗；裸钢和炮口内壁仍分别处理 |

这些数值是游戏材质试样，不是 RAL 的精确 RGB 换算，也不是四种不同迷彩漆。
深灰在正常游戏尺寸下容易吞没轮廓；首轮渲染应优先调好受光大面、炮盾、履带上缘
和车体下方的明暗分离，而不是靠全车泛白、强高光或密集划痕补救。

统一给这四辆车使用早期德国灰是用户要求的**跨年代游戏美术设定**。博物馆资料指出，
1943 年 2 月德国重装备已规定改用深黄色底漆及三色迷彩；不把豹式、虎王和战后豹式
系列统称为“闪击战时期的原装灰色车辆”。参见
[The Tank Museum：Watching Paint Dry](https://tankmuseum.org/article/watching-paint-dry/)。

## 三国目标与实施边界

| 国家 | 用户指定的四级车族 | 后续涂装目标 |
| --- | --- | --- |
| 美国 | M4 → M26 → M60 → M1 | 陆军绿色为主，深棕与近黑大斑块 |
| 苏系 | T-34 → IS-2 → T-62 → T-90 | 暖白冬季覆盖，少量暗绿底漆 |
| 德国 | 豹式 → 虎王 → 豹一 → 豹二 | 哑光深灰，大面明暗分层 |

- 上表已接入当前卡通试版。参见
  [美军参考](US_TANK_REFERENCES.md)、[苏系参考](SOVIET_TANK_REFERENCES.md)。

  `src/arcade_tank_roster.h`，Godot 造型与材质在 `godot/sample/art.gd`。
- 后续玩家四级与敌方对应车型的映射需一起核对，但不得改变碰撞、升级、炮口挂点、
  敌国排除规则、随机序列或默认镜头。少量身份标记独立于国家漆色。
- 验收需包含三国同场、默认游戏尺寸、四方向、Pixel Style 开关和 P1/P2 身份。
  当前图片不是同相机、同比例测量图，不能代替实际游戏渲染。
- 图板位于 `build/release-evidence/german-tank-references-20260926/index.html`，
  图片通过原站链接加载，需要网络；没有新增 GLB、贴图或第三方分发资产。
