# 苏系四级坦克：造型与冬季白色迷彩参考

整理日期：2026-09-26。用户指定顺序：**T-34 → IS-2 → T-62 → T-90**，
采用苏联冬季白色迷彩。这项要求取代后续苏系美术的整车红色方向。

以下保留实车照片与制作参考。2026-09-26 的[卡通试版](CARTOON_TANKS.md)已接入
T-34/76 / IS-2 / T-62 / T-90A 和暖白覆盖暗绿的涂装；等级 1–4 对应内部 level 0–3。

## 四级造型

底盘和炮塔采用三国共用的[四级尺寸标准](TANK_PROPORTIONS.md)：逐级增大，
同级大小接近。保留低矮炮塔特征时，也不能让三级或四级看起来比前一级更小。
该标准已用于卡通试版。

用户指定车族；以下子型号是本轮为保持外形一致性选定的建模参考。

| 等级 | 主参考 | 必须保留的区别 | 街机化处理 |
| --- | --- | --- | --- |
| 1 / level 0 | T-34/76 早期型，L-11 火炮 | 斜车首、较小的扁炮塔、五个大负重轮 | 强调楔形车体和小炮塔的反差，保留较短炮管；不混用 T-34/85 的大炮塔 |
| 2 / level 1 | IS-2 早期型，1944 年初藏车参考 | 饱满的厚重炮塔、大炮盾、明显的炮口制退器、六轮悬挂 | 用更宽厚的炮塔肩部与粗大炮口形成重型感，不靠把 T-34 整体放大 |
| 3 / level 2 | T-62 基本型 | 低矮圆顶炮塔、低车体、五个大负重轮、炮管上的排烟器 | 保留低圆炮塔与平滑铸造大面，但底盘占地和炮塔主体比二级更大；不添加 T-62M 的附加炮塔装甲 |
| 4 / level 3 | T-90A | 扁宽炮塔、成组反应装甲、侧裙、炮根两侧的光电装置 | 将装甲块组织成少数清晰的大组，增强顶部轮廓；不堆密集小方块 |

上述处理是原创游戏设计方向，不是实车尺寸。T-90 在 1992 年作为俄罗斯车型
列装，T-90A 资料列为 2004 年；游戏按用户要求归入苏系，不称其为苏联服役车型。[R4]
采用 T-90A，不混入 T-90M 的新炮塔、尾舱或其他改型零件。

## 冬季材质方向

以**哑光暖白覆盖暗绿底漆**为主：白色占据炮塔、上车体的主要可见面积，保留少量
宽阔、不规则的暗绿色区域。表现刷涂的覆盖关系，但省略在游戏尺寸下会变成噪点的
细密网纹、划痕和锈点。四辆车使用同一套视觉语言，具体色块布局随车体调整。

| 用途 | 游戏试样起点 | 备注 |
| --- | --- | --- |
| 冬季覆盖白 | `#E3E2D6` | 略暖、哑光，不用纯白抹平受光面 |
| 露出的暗绿底漆 | `#475541` | 大块留色，保留白色覆盖与底漆的层次 |
| 暗部与结构缝隙 | `#303931` | 用于深度，不作为随机第三色碎点 |
| 少量国家标记 | 延续 `#CD0000` | 小块红星或识别标记；不把整车恢复成红色 |

这些十六进制颜色是原创 sRGB 试样起点，不是官方色卡或照片取色。
白色覆盖面积约 70–80% 可作为首轮材质实验，**不是历史规定**。
在 T-90A 上采用同一套冬季处理是游戏统一美术设计；本轮没有核实四个具体型号
均采用相同花纹的历史依据。

2026-09-26 的后续德国要求已改为哑光深灰，参见[德国参考](GERMAN_TANK_REFERENCES.md)。
三国目标现在是美军绿色 + 棕黑斑、苏系暖白 + 暗绿、德国深灰；德国运行材质
现已同步为深灰。识别仍需结合轮廓与少量国家标记，并保留独立的
P1/P2 标记、敌人状态标记和加成提示。
履带橡胶、裸露钢材、镜片和炮口内壁不能被白漆统一染白。
